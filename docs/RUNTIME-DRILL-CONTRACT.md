# Runtime drill contract

The source workout defines a slot: its wording, source IDs, duration or repetitions, rest, and demo links. The slot is immutable. A session fills that slot with a versioned `WorkoutActivityInstance`. A conditioning slot can therefore be jumping jacks, burpees, box jumps, squat jumps, or the boxer's named choice without rewriting the source workout. A change of choice appends a new instance; timer intervals and pose candidates retain the old instance ID.

Each reviewed movement definition declares a family, equipment, required camera view, observable phase sequence, and target unit. For example, box jumps need the boxer **and box** in view and a floor → flight → box landing → reset sequence. Burpees need the floor visible and a standing → floor → standing sequence. The definition describes evidence needed for a future detector. It does not turn an unimplemented detector on.

The `ActivityMeasurementRecipe` records what the current app can actually measure. Squats and lunges can emit unvalidated rep candidates; boxing and shadowboxing can emit unvalidated exchange candidates. Jumping jacks, burpees, box jumps, squat jumps, frontal stance, mobility, push-ups, and bench press currently record elapsed time only. A free-form custom activity also records time only. A generic mobility slot cannot have movement-specific pose rules until the exact mobility movement is selected and reviewed. If camera placement hides required body parts or equipment, the live app should keep the clock running and abstain from counting.

Every completion receipt carries source block/item IDs, activity instance ID, definition version, measurement recipe and validation status. MLflow can join those IDs to pose windows, candidate events, corrections, and model training runs. Training labels must come from reviewed footage; a timer, model proposal, or user's choice is not a verified rep. Promote a new detector only after testing it across side, floor, behind, partial-body, and occluded phone placements on held-out sessions. Keep French and English labels as presentation fields over the same movement keys.
